# Menú diario

Aplicación web para menú corporativo, pedidos y administración. El código está en la carpeta **`web`**.

## Arranque rápido (desarrollo)

1. Creá `web/.env` desde `web/.env.example` (Postgres local o Supabase).
2. `cd web && npm install && npx prisma migrate dev && npm run dev`
